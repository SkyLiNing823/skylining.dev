# skylining.dev

Personal website for Tien-Ning (Sky) Lee.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- MDX-ready writing system
- lucide-react icons

## Local development

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Notes

- Projects and Writing are intentionally placeholders for now.
- Resume content is centralized in `lib/site-data.ts`.
- Contact links use lucide-react icons. Brand-specific SVG icons can be added later if desired.
